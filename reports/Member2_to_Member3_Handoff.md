## 1. `geo_utils.py`

**Path:** `src/geo_utils.py`

**Purpose:** Shared geospatial library used by every downstream script: loads 7-band rasters and builds the 9-feature stack (6 bands + NDVI/NDBI/NDWI), samples the 10 m label raster at satellite pixel centers, runs model prediction over rasters, writes GeoTIFF/PNG maps, converts pixel counts to km2, builds 4x4 transition matrices.

**Inputs:** Member 1 rasters (read-only)

**Outputs:** functions consumed by downstream scripts

**Used by / fits in:** imported by predict_lulc, change_analysis, transition_areas, verify_outputs, make_figures, final_results (paths)

**Complete source code:**

```python
"""
GeoRAG - Member 2 - Shared geospatial helpers
=============================================
Small utility functions used by all Phase D scripts. Keeping them in one
place means every script treats the data exactly the same way.

Beginner notes:
- "transform"  : an affine object inside a GeoTIFF that converts
                 (row, col) pixel positions -> (longitude, latitude).
- "sampling"   : reading a value from the label raster at the same
                 geographic location as a satellite pixel. The label raster
                 is finer (10 m) than the satellite (30 m), so we look up
                 which label pixel sits under each satellite pixel center.
- "nodata"     : we encode "no prediction / outside image" as 255 (uint8).
"""

from pathlib import Path

import numpy as np
import rasterio
from rasterio import Affine

ROOT = Path(__file__).resolve().parents[1]
GEO = ROOT / "GeoRag"

SAT = {
    2015: GEO / "GeoRAG_Satellite" / "Vijayawada_Landsat_2015.tif",
    2020: GEO / "GeoRAG_Satellite" / "Vijayawada_Landsat_2020.tif",
}
PLAIN = {
    "2015": GEO / "GeoRAG_Satellite" / "2015.tif",
    "2025": GEO / "GeoRAG_Satellite" / "2025.tif",
}
LABELS = {
    y: GEO / "GeoRAG_LandUse_Labels" / f"Vijayawada_LandUse_Labels_{y}.tif"
    for y in (2015, 2020, 2025)
}
MODELS = ROOT / "models"
RESULTS = ROOT / "results"
MAPS = ROOT / "maps"
PRED_DIR = ROOT / "predictions"
for d in (RESULTS, MAPS, PRED_DIR):
    d.mkdir(exist_ok=True)

CLASS_NAMES = {1: "Built-up", 2: "Vegetation", 3: "Water", 4: "Open Land"}
CLASSES = [1, 2, 3, 4]
NODATA = 255

# Classic Landsat band names inside the rasters (verified in Step 1/2).
BAND_ORDER = ["blue", "green", "red", "nir", "swir1", "swir2", "thermal"]
FEATURES = BAND_ORDER[:6] + ["ndvi", "ndbi", "ndwi"]  # model input layout


def safe_div(a, b):
    """(a-b)/(a+b) that returns NaN instead of warning when a+b == 0."""
    with np.errstate(divide="ignore", invalid="ignore"):
        return (a - b) / (a + b)


def load_feature_stack(path):
    """
    Read a 7-band satellite raster and build the 9-feature stack
    (6 bands + NDVI + NDBI + NDWI) exactly as in the training CSVs.
    Returns (X [H*W, 9] float32, bands_finite [H*W] bool, shape (H, W)).
    """
    with rasterio.open(path) as src:
        arr = src.read()
        transform = src.transform
        crs = src.crs
    h, w = arr.shape[1], arr.shape[2]
    blue, green, red, nir, s1, s2 = (arr[i].astype(np.float32) for i in range(6))
    stack = np.stack([blue, green, red, nir, s1, s2,
                      safe_div(nir, red), safe_div(s1, nir), safe_div(green, nir)], -1)
    bands_finite = np.isfinite(stack[..., :6]).all(axis=-1)
    return stack.reshape(-1, 9), bands_finite.reshape(-1), (h, w), transform, crs


def sample_labels_at(lab_path, transform, shape):
    """
    For every satellite pixel center, fetch the label-raster value underneath.
    Returns flat uint8 array (255 = outside image / class 0).
    """
    h, w = shape
    with rasterio.open(lab_path) as lsrc:
        lab = lsrc.read(1)
        ltr = lsrc.transform
    rows, cols = np.mgrid[0:h, 0:w]
    xs = transform.c + (cols + 0.5) * transform.a + (rows + 0.5) * transform.b
    ys = transform.f + (cols + 0.5) * transform.d + (rows + 0.5) * transform.e
    lcols, lrows = (~ltr) * (xs, ys)
    lcols = np.floor(lcols).astype(np.int64)
    lrows = np.floor(lrows).astype(np.int64)
    ok = (lrows >= 0) & (lrows < lab.shape[0]) & (lcols >= 0) & (lcols < lab.shape[1])
    out = np.full(h * w, NODATA, np.uint8)
    out[ok.reshape(-1)] = lab.reshape(-1)[(lrows * lab.shape[1] + lcols)[ok]]
    return out


def predict_raster(model, X, valid_mask, shape):
    """Run the model on all valid pixels; returns 2-D uint8 (255 = unclassified)."""
    pred = np.full(shape[0] * shape[1], NODATA, np.uint8)
    pred[valid_mask] = model.predict(X[valid_mask].astype(np.float32)).astype(np.uint8) + 1
    return pred.reshape(shape)


def save_map(path, arr2d, transform, crs):
    """Write a single-band uint8 GeoTIFF (GeoTIFF = a PNG that knows where it is on Earth)."""
    profile = dict(driver="GTiff", height=arr2d.shape[0], width=arr2d.shape[1],
                   count=1, dtype="uint8", crs=crs, transform=transform,
                   nodata=NODATA, compress="deflate")
    with rasterio.open(path, "w", **profile) as dst:
        dst.write(arr2d, 1)


CLASS_COLORS = {1: (200, 30, 30), 2: (40, 160, 60), 3: (40, 90, 200), 4: (230, 200, 60)}


def save_png(path, arr2d, title=""):
    """Save a colorized PNG preview (red=Built-up, green=Vegetation, blue=Water, yellow=Open)."""
    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt
    from matplotlib import colors as mcolors, patches as mpatches
    cmap = mcolors.ListedColormap(
        [(1, 1, 1)] + [tuple(c / 255 for c in CLASS_COLORS[c]) for c in CLASSES]
    )
    img = np.full(arr2d.shape, 0, np.uint8)
    for c in CLASSES:
        img[arr2d == c] = c
    fig, ax = plt.subplots(figsize=(7, 7))
    ax.imshow(img, cmap=cmap, vmin=0, vmax=4, interpolation="nearest")
    handles = [mpatches.Patch(color=tuple(v / 255 for v in CLASS_COLORS[c]),
                              label=f"{c} {CLASS_NAMES[c]}") for c in CLASSES]
    ax.legend(handles=handles, loc="upper right", fontsize=8)
    ax.set_title(title)
    ax.axis("off")
    fig.tight_layout()
    fig.savefig(path, dpi=150)
    plt.close(fig)


def area_table(pred2d, transform, inside_mask=None):
    """
    Pixel counts -> area per class.
    Deg^2 pixel area is projected to km^2 with a local cos(latitude) factor
    (accurate at city scale; documented in the report).
    """
    px_area_deg2 = abs(transform.a * transform.e)
    mid_lat = None  # filled by caller if needed; default 16.5 (Vijayawada)
    lat = 16.5 if mid_lat is None else mid_lat
    m_per_deg_lat = 111_320.0
    m_per_deg_lon = 111_320.0 * np.cos(np.deg2rad(lat))
    px_km2 = px_area_deg2 * m_per_deg_lon * m_per_deg_lat / 1e6
    counts = {}
    for c in CLASSES:
        m = (pred2d == c)
        if inside_mask is not None:
            m = m & inside_mask
        counts[c] = int(m.sum())
    total = sum(counts.values())
    return {c: dict(pixels=counts[c], area_km2=round(counts[c] * px_km2, 2))
            for c in CLASSES}, total, px_km2


def transition_matrix(a2d, b2d, inside_mask=None):
    """Count transitions a->b between two classified rasters (same grid)."""
    T = np.zeros((4, 4), np.int64)
    m = (a2d <= 4) & (b2d <= 4)
    if inside_mask is not None:
        m &= inside_mask
    for la in CLASSES:
        for lb in CLASSES:
            T[la - 1, lb - 1] = int(((a2d == la) & (b2d == lb) & m).sum())
    return T
```

```python
"""
GeoRAG - Member 2 - Step 1: Inspect all raster files
====================================================
WHAT THIS DOES (beginner version):
A GeoTIFF is like a PNG photo, but every pixel is a number and the file
"knows" its real-world location (CRS = coordinate reference system) and
pixel size (resolution, in meters for projected maps).

We print, for every raster:
  - width x height  (number of pixels)
  - number of bands (a band = one "color layer", e.g. Red, NIR...)
  - CRS             (the "address system" of the map, e.g. EPSG:32644)
  - resolution      (real-world size of one pixel, here 30 m = Landsat)
  - nodata value    (the number that means "no information here")
  - min/max/mean of a few pixels (quick sanity check that data is real)

This is READ-ONLY: we open files, we never modify them.
"""

from pathlib import Path

import numpy as np
import rasterio

ROOT = Path(__file__).resolve().parents[1]
GEO = ROOT / "GeoRag"

FILES = [
    GEO / "GeoRAG_Satellite" / "Vijayawada_Landsat_2015.tif",

for f in FILES:
    print("=" * 78)
    if not f.exists():

    with rasterio.open(f) as src:
        print(f"FILE    : {f.relative_to(ROOT)}")
```

```python
GeoRAG - Member 2 - Phase B: Baseline ML (Random Forest + XGBoost)
==================================================================
Per-year LULC classification baseline.

Design decisions (documented for the project report):
- Deduplicate exact duplicate rows BEFORE splitting (prevents train/test leakage).
- Stratified 80/20 split (preserves class proportions).
- Labels remapped 1..4 -> 0..3 internally for XGBoost; reports use original codes.
  1 = Built-up, 2 = Vegetation, 3 = Water, 4 = Open Land
- 'Year' is NOT used as a feature (metadata, constant within each year file).
- No spatial coordinates exist in the CSVs -> limitation documented, not hidden.
- Known limitation: random pixel split may be optimistic (spatial autocorrelation).

Run from project root:  python src/run_baseline.py
"""

import time
import json
from pathlib import Path

import joblib
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import xgboost as xgb
from sklearn.ensemble import RandomForestClassifier

        colsample_bytree=0.8,
        random_state=RANDOM_STATE,
        n_jobs=-1,

for year, path in FILES.items():
```

## 5. `temporal_validation.py`

**Path:** `src/temporal_validation.py`

**Purpose:** Temporal experiments: train 2015 -> test 2020/2025 and train 2015+2020 -> test 2025 (each model trained once per training set).

**Inputs:** training CSVs

**Outputs:** results/temporal_validation_results.csv

**Used by / fits in:** superseded in reporting by final_results.py (identical numbers, verified)

**Complete source code:**

```python
"""
GeoRAG - Member 2 - Temporal validation experiment
==================================================
WHY (beginner version):
The Phase B scores (accuracy ~84-90%) came from splitting ONE year's pixels
randomly into train/test. Neighboring pixels look almost identical, so the
model is partly "quizzed on questions it has seen". That inflates scores.

A harder, more honest test: TRAIN on the PAST, TEST on the FUTURE.
  A) train 2015 -> test 2020
  B) train 2015 -> test 2025
  C) train 2015+2020 -> test 2025
If the model still works on a year it never saw, it truly learned what
built-up/vegetation/water/open-land "look like".

NOTE: 2025 pixels are not 100% usable (zero-band issue) - for this experiment
we use only fully finite rows, same rule for train and test, so the
comparison stays fair.

Outputs: results/temporal_validation_results.csv (+ printed table)

Run from project root:  python src/temporal_validation.py
"""

import time
from pathlib import Path

import joblib
import numpy as np
import pandas as pd
import xgboost as xgb
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, cohen_kappa_score, f1_score

from geo_utils import MODELS, RESULTS

ROOT = Path(__file__).resolve().parents[1]
CSV = {2015: ROOT / "data" / "training_2015.csv",
       2020: ROOT / "data" / "training_2020.csv",
       2025: ROOT / "data" / "training_2025.csv"}
FEATURES = ["Blue", "Green", "Red", "NIR", "SWIR1", "SWIR2", "NDVI", "NDBI", "NDWI"]


def load_year(y):
    df = pd.read_csv(CSV[y]).drop_duplicates(subset=FEATURES + ["Label"])
    X = df[FEATURES].to_numpy(np.float32)
    yv = df["Label"].to_numpy(np.int64)
    return X, yv


EXPERIMENTS = [([2015], [2020, 2025]), ([2015, 2020], [2025])]  # train once, test many
rows = []

cache = {y: load_year(y) for y in (2015, 2020, 2025)}

for train_years, test_years in EXPERIMENTS:
    Xtr = np.vstack([cache[y][0] for y in train_years])
    ytr = np.hstack([cache[y][1] - 1 for y in train_years])
    print(f"training on {train_years}: {len(Xtr):,} rows")

    for name, mdl in [
        ("RF", RandomForestClassifier(n_estimators=200, random_state=42,
                                      n_jobs=-1, class_weight="balanced")),
        ("XGB", xgb.XGBClassifier(n_estimators=300, max_depth=6, learning_rate=0.05,
                                  subsample=0.8, colsample_bytree=0.8, random_state=42,
                                  n_jobs=-1, tree_method="hist", eval_metric="mlogloss")),
    ]:
        t0 = time.time()
        mdl.fit(Xtr, ytr)
        dt = time.time() - t0
        print(f"  {name} fit done in {dt:.1f}s")
        for test_year in test_years:
            Xte, yte = cache[test_year]
            pred = mdl.predict(Xte) + 1
            rows.append(dict(
                train_years="+".join(map(str, train_years)), test_year=test_year, model=name,
                accuracy=round(accuracy_score(yte, pred), 4),
                kappa=round(cohen_kappa_score(yte, pred), 4),
                macro_f1=round(f1_score(yte, pred, average="macro"), 4),
                fit_seconds=round(dt, 1)))
            print(f"    -> test {test_year} [{name}]: acc={rows[-1]['accuracy']:.4f} "
                  f"kappa={rows[-1]['kappa']:.4f} macroF1={rows[-1]['macro_f1']:.4f}")

# baseline: same-year random split scores from Phase B for comparison
phaseB = pd.read_csv(RESULTS / "accuracy_results.csv")[["year", "model", "accuracy"]]
print("\nPhase B (same-year random split) accuracies for reference:")
print(phaseB.to_string(index=False))

out = pd.DataFrame(rows)
out.to_csv(RESULTS / "temporal_validation_results.csv", index=False)
print(f"\nSaved {RESULTS / 'temporal_validation_results.csv'}")

```

## 6. `final_results.py`

**Path:** `src/final_results.py`

**Purpose:** Checkpointed recomputation of ALL 12 experiments (6 same-year + 6 temporal) with macro precision/recall; merges into the master table.

**Inputs:** training CSVs

**Outputs:** results/final_model_results.csv (+ per-pass CSVs)

**Used by / fits in:** consumed by README/handoff/figures

**Complete source code:**

```python
"""
GeoRAG - Member 2 - Final consolidated results (checkpointed)
=============================================================
Recomputes the six same-year experiments AND the temporal experiments from
scratch and writes one master table:

    results/final_model_results.csv
    (Training_Years, Test_Year, Model, Accuracy, Precision_Macro,
     Recall_Macro, F1_Macro, Kappa)

Usage (three passes, each well under the 10-minute command limit):

    python src/final_results.py sameyear    # ~3-4 min (RF on 2015 is the big one)
    python src/final_results.py temporal1   # train 2015 -> test 2020+2025 (~4 min)
    python src/final_results.py temporal2   # train 2015+2020 -> test 2025 (~4 min)
    python src/final_results.py merge       # combine + reproducibility check

Methodology (identical to earlier runs, fixed random_state=42):
- predictors: only the 9 spectral features (no Label, no Year)
- dedupe before splitting; stratified 80/20 for same-year runs
- temporal runs train on ALL rows of the training year(s) (that is the
  experiment's definition), test on whole unseen years
- no preprocessing, no tuning: test labels are never used for anything
  except final scoring
"""
import sys
import time
from pathlib import Path

import numpy as np
import pandas as pd
import xgboost as xgb
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (accuracy_score, cohen_kappa_score,
                             f1_score, precision_score, recall_score)
from sklearn.model_selection import train_test_split

ROOT = Path(__file__).resolve().parents[1]
RES = ROOT / "results"
CSV = {2015: ROOT / "data/training_2015.csv",
       2020: ROOT / "data/training_2020.csv",
       2025: ROOT / "data/training_2025.csv"}
FEATURES = ["Blue", "Green", "Red", "NIR", "SWIR1", "SWIR2", "NDVI", "NDBI", "NDWI"]


def load(y):
    df = pd.read_csv(CSV[y]).drop_duplicates(subset=FEATURES + ["Label"])
    return df[FEATURES].to_numpy(np.float32), df["Label"].to_numpy(np.int64)


def models():
    return [
        ("RF", RandomForestClassifier(n_estimators=200, random_state=42,
                                      n_jobs=-1, class_weight="balanced")),
        ("XGB", xgb.XGBClassifier(n_estimators=300, max_depth=6, learning_rate=0.05,
                                  subsample=0.8, colsample_bytree=0.8, random_state=42,
                                  n_jobs=-1, tree_method="hist", eval_metric="mlogloss")),
    ]


def score(train_label, ty, name, mdl, Xte, yte, fit_s):
    pred = mdl.predict(Xte) + 1
    return dict(Training_Years=train_label, Test_Year=ty, Model=name,
                Accuracy=round(accuracy_score(yte, pred), 4),
                Precision_Macro=round(precision_score(yte, pred, average="macro"), 4),
                Recall_Macro=round(recall_score(yte, pred, average="macro"), 4),
                F1_Macro=round(f1_score(yte, pred, average="macro"), 4),
                Kappa=round(cohen_kappa_score(yte, pred), 4),
                fit_seconds=round(fit_s, 1))


rows = []
mode = sys.argv[1]

cache = {y: load(y) for y in (2015, 2020, 2025)}

if mode == "sameyear":
    for y in (2015, 2020, 2025):
        X, yv = cache[y]
        i_tr, i_te = train_test_split(np.arange(len(yv)), test_size=0.20,
                                      random_state=42, stratify=yv)
        for name, mdl in models():
            t0 = time.time()
            mdl.fit(X[i_tr], yv[i_tr] - 1)
            dt = time.time() - t0
            rows.append(score(str(y), y, name, mdl, X[i_te], yv[i_te], dt))
            print(f"{y} {name}: acc={rows[-1]['Accuracy']} F1m={rows[-1]['F1_Macro']} "
                  f"kappa={rows[-1]['Kappa']} ({dt:.0f}s)")

elif mode == "temporal1":
    Xtr = cache[2015][0]
    ytr = cache[2015][1] - 1
    print(f"train 2015: {len(Xtr):,} rows")
    for name, mdl in models():
        t0 = time.time()
        mdl.fit(Xtr, ytr)
        dt = time.time() - t0
        print(f"  {name} fit {dt:.0f}s")
        for ty in (2020, 2025):
            Xte, yte = cache[ty]
            rows.append(score("2015", ty, name, mdl, Xte, yte, dt))
            print(f"  -> {ty}: acc={rows[-1]['Accuracy']} F1m={rows[-1]['F1_Macro']}")

elif mode == "temporal2":
    Xtr = np.vstack([cache[2015][0], cache[2020][0]])
    ytr = np.hstack([cache[2015][1] - 1, cache[2020][1] - 1])
    print(f"train 2015+2020: {len(Xtr):,} rows")
    for name, mdl in models():
        t0 = time.time()
        mdl.fit(Xtr, ytr)
        dt = time.time() - t0
        print(f"  {name} fit {dt:.0f}s")
        Xte, yte = cache[2025]
        rows.append(score("2015+2020", 2025, name, mdl, Xte, yte, dt))
        print(f"  -> 2025: acc={rows[-1]['Accuracy']} F1m={rows[-1]['F1_Macro']}")

elif mode == "merge":
    parts = []
    for p in ["final_sameyear.csv", "final_temporal1.csv", "final_temporal2.csv"]:
        fp = RES / p
        if fp.exists():
            parts.append(pd.read_csv(fp))
    combined = pd.concat(parts, ignore_index=True)
    order = {"2015": 0, "2020": 1, "2025": 2, "2015+2020": 3}
    combined = combined.sort_values(
        by=["Training_Years", "Test_Year", "Model"],
        key=lambda s: s.map(order) if s.name == "Training_Years" else s).reset_index(drop=True)
    combined.to_csv(RES / "final_model_results.csv", index=False)
    print("Saved", RES / "final_model_results.csv")
    print(combined.drop(columns=["fit_seconds"]).to_string(index=False))

    # ---- reproducibility check vs the earlier temporal run
    print("\n== REPRODUCIBILITY: temporal metrics vs earlier run ==")
    prev = pd.read_csv(RES / "temporal_validation_results.csv")
    ok_all = True
    for _, r in prev.iterrows():
        m = combined[(combined.Training_Years == r.train_years)
                     & (combined.Test_Year == int(r.test_year))
                     & (combined.Model == r.model)]
        if m.empty:
            continue
        match = abs(float(r.accuracy) - float(m.Accuracy.iloc[0])) < 1e-6
        ok_all &= match
        print(f"  train {r.train_years} -> test {int(r.test_year)} [{r.model}]: "
              f"earlier={r.accuracy:.4f} recomputed={m.Accuracy.iloc[0]:.4f} "
              f"{'MATCH' if match else 'MISMATCH'}")
    print("RESULT:", "ALL TEMPORAL RESULTS REPRODUCIBLE" if ok_all
          else "REPRODUCIBILITY FAILURE")

else:
    sys.exit("usage: python src/final_results.py [sameyear|temporal1|temporal2|merge]")

if mode != "merge":
    out = RES / {"sameyear": "final_sameyear.csv",
                 "temporal1": "final_temporal1.csv",
                 "temporal2": "final_temporal2.csv"}[mode]
    pd.DataFrame(rows).to_csv(out, index=False)
    print("Saved", out)

```

## 7. `verify_reproducibility.py`

**Path:** `src/verify_reproducibility.py`

**Purpose:** Reads final_model_results.csv and temporal_validation_results.csv from disk and asserts exact agreement (6/6).

**Inputs:** the two results CSVs

```python
"""
GeoRAG - Member 2 - Standalone reproducibility check
====================================================
Reads results/final_model_results.csv and results/temporal_validation_results.csv
FROM DISK and verifies every temporal experiment's accuracy matches exactly.
No retraining: this compares persisted, computed results.
"""
import pandas as pd

RES = "results/"
comb = pd.read_csv(RES + "final_model_results.csv")
prev = pd.read_csv(RES + "temporal_validation_results.csv")

ok_all = True
n_checked = 0
for _, r in prev.iterrows():
    ty = int(r["test_year"])
    m = comb[(comb["Training_Years"].astype(str) == str(r["train_years"]))
             & (comb["Test_Year"].astype(int) == ty)
             & (comb["Model"].astype(str) == str(r["model"]))]
    if len(m) != 1:
        print(f"  train {r['train_years']} -> test {ty} [{r['model']}]: "
              f"FOUND {len(m)} rows in final_model_results.csv (expected 1)")
        ok_all = False
        continue
    a_old, a_new = float(r["accuracy"]), float(m["Accuracy"].iloc[0])
    k_old, k_new = float(r["kappa"]), float(m["Kappa"].iloc[0])
    f_old, f_new = float(r["macro_f1"]), float(m["F1_Macro"].iloc[0])
    match = (abs(a_old - a_new) < 1e-6 and abs(k_old - k_new) < 1e-6
             and abs(f_old - f_new) < 1e-6)
    ok_all &= match
    n_checked += 1
    print(f"  train {r['train_years']} -> test {ty} [{r['model']}]: "
          f"acc {a_old:.4f}={a_new:.4f}, kappa {k_old:.4f}={k_new:.4f}, "
          f"F1m {f_old:.4f}={f_new:.4f}  {'MATCH' if match else 'MISMATCH'}")

print(f"\n{n_checked}/6 temporal experiments checked")
print("VERDICT:", "ALL TEMPORAL RESULTS REPRODUCIBLE (exact match)"
      if ok_all and n_checked == 6 else "REPRODUCIBILITY FAILURE - INVESTIGATE")
```

## 8. `predict_lulc.py`

**Path:** `src/predict_lulc.py`

**Purpose:** Phase D: applies RF and XGB to every valid pixel of the big 2015/2020 rasters and the 2025 window; validates each map against the label raster (agreement %, per-class P/R/F1); writes GeoTIFF + PNG + area tables.

**Inputs:** models/*.pkl, GeoRag satellite + label rasters

**Outputs:** predictions/LULC_pred_*.tif, results/raster_validation_*, raster_prediction_summary.csv

**Used by / fits in:** feeds change_analysis.py and all maps/figures

**Complete source code:**

```python
"""
GeoRAG - Member 2 - Phase D: LULC prediction + validation
=========================================================
WHAT THIS DOES (beginner version):
1. Loads our trained XGBoost and Random Forest models (from Phase B).
2. Feeds them EVERY valid pixel of the big 2015 and 2020 satellite images
   -> produces full LULC maps (our own predictions, not Member 1's).
3. For 2025, predicts only the small healthy window of 2025.tif.
4. "Grades" every prediction against Member 1's label rasters
   (agreement % + confusion matrix) and saves everything:
     predictions/*.tif   full-geo maps for Member 4 (GIS)
     maps/*.png          colored previews for the report
     results/*.csv       accuracy + class-share tables
"""

import time
from collections import Counter

import joblib
import numpy as np
import pandas as pd

from geo_utils import (BAND_ORDER, CLASS_NAMES, CLASSES, LABELS, MAPS, MODELS,
                       NODATA, PRED_DIR, RESULTS, SAT, PLAIN, area_table,
                       load_feature_stack, predict_raster, sample_labels_at,
                       save_map, save_png)

rows = []

for year in (2015, 2020):
    print("=" * 78)
    print(f"YEAR {year} - {SAT[year].name}")
    X, bands_ok, shape, tr, crs = load_feature_stack(SAT[year])
    h, w = shape
    print(f"  grid {w}x{h}, pixels with complete bands: {int(bands_ok.sum()):,}")

    lab = sample_labels_at(LABELS[year], tr, shape)
    inside = (lab > 0) & (lab <= 4) & bands_ok          # compare only there

    for mname in ("XGB", "RF"):
        model = joblib.load(MODELS / f"{mname}_{year}.pkl")
        t0 = time.time()
        pred = predict_raster(model, X, bands_ok, shape)
        dt = time.time() - t0
        print(f"  {mname}: predicted {int((pred != NODATA).sum()):,} px in {dt:.1f}s")

        # ---- validation against label raster
        p, l = pred.ravel()[inside], lab[inside]
        agree = float((p == l).mean())
        cm = np.zeros((4, 4), np.int64)
        for la, pb in zip(l, p):
            cm[la - 1, pb - 1] += 1
        per_class = {}
        for i, c in enumerate(CLASSES):
            tp = cm[i, i]
            prec = tp / cm[:, i].sum() if cm[:, i].sum() else 0.0
            rec = tp / cm[i, :].sum() if cm[i, :].sum() else 0.0
            f1 = 2 * prec * rec / (prec + rec) if (prec + rec) else 0.0
            per_class[c] = dict(precision=round(prec, 4), recall=round(rec, 4),
                                f1=round(f1, 4), support=int(cm[i, :].sum()))
        print(f"    agreement vs labels: {agree * 100:.2f}%  | " +
              "  ".join(f"{CLASS_NAMES[c]} F1={per_class[c]['f1']:.3f}" for c in CLASSES))

        # ---- class shares (valid pixels only)
        tot = int((pred != NODATA).sum())
        shares = Counter(pred[pred != NODATA].tolist())
        share_txt = {CLASS_NAMES[c]: f"{shares.get(c, 0) / tot * 100:.1f}%" for c in CLASSES}
```

```python
"""
GeoRAG - Member 2 - Output verification (final QA)
==================================================
Independently verifies, for every produced LULC/change GeoTIFF:
  - CRS, dimensions, transform, bounds, nodata
  - class values are only {1,2,3,4} + nodata(255)
  - alignment with the source satellite raster of the same year
Then cross-checks area statistics TWO WAYS:
  A) our cos(latitude) degree-based approximation
  B) independent on-the-fly reprojection to UTM 44N (metric CRS)
and writes results/output_verification.csv.
READ-ONLY: no raster is modified.
"""
import numpy as np
import pandas as pd
import rasterio
from rasterio.warp import calculate_default_transform, reproject, Resampling

from geo_utils import (CLASS_NAMES, CLASSES, LABELS, MAPS, NODATA, PRED_DIR,
                       RESULTS, SAT)

rows = []


def check(path, expect_aligned_with=None, label=""):
    with rasterio.open(path) as src:
        arr = src.read(1)
        vals = set(np.unique(arr[arr != src.nodata]).tolist()) if src.nodata is not None \
            else set(np.unique(arr).tolist())
        rec = dict(file=path.name, label=label, crs=str(src.crs),
                   width=src.width, height=src.height,
                   res_deg=round(abs(src.transform.a), 8),
                   bounds=",".join(f"{b:.5f}" for b in src.bounds),
                   nodata=src.nodata,
                   classes=sorted(int(v) for v in vals if v <= 4),
                   bad_classes=sorted(int(v) for v in vals if v not in CLASSES))
        aligned = None
        if expect_aligned_with is not None:
            with rasterio.open(expect_aligned_with) as ref:
                aligned = (src.width == ref.width and src.height == ref.height
                           and np.allclose(src.transform, ref.transform)
                           and str(src.crs) == str(ref.crs))
        rec["aligned_with_source"] = aligned
        rows.append(rec)
        return src, arr


print("== LULC predictions ==")
sat = {y: SAT[y] for y in (2015, 2020)}
src15, _ = check(PRED_DIR / "LULC_pred_2015_XGB.tif", sat[2015], "prediction 2015")

    pass

def area_two_ways(path, inside_only=True):
    with rasterio.open(path) as src:
        arr = src.read(1)
        tr, crs = src.transform, src.crs
        bounds = src.bounds
    # A) degree approximation: px_deg2 * (m/deg-lat) * (m/deg-lon) -> m^2 -> km^2
    px_deg2 = abs(tr.a * tr.e)
    px_km2_deg = px_deg2 * M_LAT * (M_LAT * LON_F) / 1e6
    # B) UTM reprojection (independent, metric)
    left, bottom, right, top = bounds
    tr_utm, w, h = calculate_default_transform(
        crs, "EPSG:32644", src.width, src.height, left, bottom, right, top)
    px_km2_utm = abs(tr_utm.a * tr_utm.e) / 1e6
    out = {}
    src_data = arr
    for cls in CLASSES:
        n_deg = int((src_data == cls).sum())
        dst = np.zeros((h, w), np.uint8)
        reproject(src_data, dst, src_transform=tr, src_crs=crs,
                  dst_transform=tr_utm, dst_crs="EPSG:32644",
                  resampling=Resampling.nearest)
        n_utm = int((dst == cls).sum())
        out[cls] = dict(km2_deg=round(n_deg * px_km2_deg, 2),
                        km2_utm=round(n_utm * px_km2_utm, 2))
    return out
```

# PART E - HOW THE MAIN CODE WORKS (PLAIN LANGUAGE)

## Data loading
Training CSVs are read with pandas.read_csv into 11-column frames; the
prediction path reads GeoTIFFs with rasterio.open(...).read() into band
stacks. In geo_utils.load_feature_stack the six spectral bands plus three
computed indices form one (H*W, 9) feature matrix.

## Feature selection
Exactly nine predictors are selected by name in every training script:
FEATURES = [Blue, Green, Red, NIR, SWIR1, SWIR2, NDVI, NDBI, NDWI].
Label is the target (what we predict) and is never a predictor. Year is
never a predictor - it is used only to define which rows belong to which
temporal experiment. The indices are verified deterministic functions of the
bands: NDVI=(NIR-Red)/(NIR+Red), NDBI=(SWIR1-NIR)/(SWIR1+NIR),
NDWI=(Green-NIR)/(Green+NIR).

## Model training
Random Forest: 200 trees, class_weight='balanced' (compensates documented
imbalance, e.g. Open Land 2.8% in 2015). XGBoost: 300 trees, depth 6,
learning rate 0.05, subsample/colsample 0.8, histogram trees; labels are
remapped 1..4 -> 0..3 internally because the library requires zero-based
classes. Both use random_state=42. There is no scaling and no search:
tree models split on raw feature values, and no hyperparameter ever saw a
test label.

## Same-year validation
run_baseline.py (and identically final_results.py sameyear): exact duplicate
rows are dropped BEFORE splitting, then train_test_split(..., test_size=0.20,
random_state=42, stratify=y) performs a stratified random PIXEL split: class
proportions are preserved in both sets. Neighboring pixels can land in both
sets, so this is explicitly NOT spatial validation.

## Temporal validation
temporal_validation.py / final_results.py temporal1|temporal2: the model is
fitted on ALL rows of the training year(s) - 2015 only (332,210 rows after
dedupe) or 2015+2020 (387,097 rows) - and then predicts whole unseen years:
2015->2020, 2015->2025, 2015+2020->2025. Each model trains once per training
set and is reused for every applicable test year. Test-year rows never touch
training or tuning.

## Prediction over a raster
predict_lulc.py + geo_utils.load_feature_stack/predict_raster: the satellite
raster is flattened to one row per pixel, a boolean mask keeps only pixels
whose six bands are all finite, the fitted model predicts class 1..4 for
exactly those pixels, and everything else becomes 255 (NoData). The flat
vector is reshaped back to the raster grid and written with the ORIGINAL
transform + CRS, so the map stays georeferenced.

## Change detection
change_analysis.py + geo_utils.transition_matrix: for two classified rasters
on the same grid, every pixel contributes one (from, to) class pair; counts
accumulate into a 4x4 matrix (rows = from, columns = to). Change rasters
encode each pixel as from*10+to. Built-up expansion means transitions INTO
class 1 (codes ending in 1: 21, 31, 41); Built-up->Vegetation (12) is NOT
urban expansion.

## Area calculation
geo_utils.area_table: pixel count x pixel area. Pixel area comes from the
raster transform (degrees^2) converted with 111,320 m/deg latitude and
cos(16.5 deg) for longitude. verify_outputs.py re-projected every raster to
metric UTM 44N and recomputed areas independently: the two methods agree
within 0.4-1.0% (results/area_crosscheck_utm.csv), so the degree-based
shortcut is defensible at city scale.

## Output verification
verify_outputs.py opens every produced GeoTIFF and checks CRS, dimensions,
transform, bounds, nodata, that class values are only {1,2,3,4}, and pixel-
perfect alignment with the source raster of the same year. Results are in
results/output_verification.csv; all rows passed.

# PART G - LULC CLASS DEFINITIONS

1 = Built-up (red in PNGs) | 2 = Vegetation (green) | 3 = Water (blue) |
4 = Open Land (yellow) | 255 = NoData (excluded everywhere).

In PREDICTION rasters each pixel holds one class value 1-4 (or 255). In
CHANGE rasters each pixel holds a two-digit transition code (from*10+to), so
class meanings combine: code 21 means 'was Vegetation, now Built-up'. Class 0
exists ONLY in Member 1's label rasters (outside city) - it never appears in
Member 2 outputs, which use 255 for NoData instead.

# PART H - CHANGE ENCODING (ACTUAL PROJECT VALUES)

Encoding: code = from_class * 10 + to_class. Verified real examples from
this project (all measured, none invented):

| Code | Transition | Verified count (10 m px) |
|---|---|---|
| 21 | Vegetation -> Built-up | 166,944 (2015-2020); 264,075 (2015-2025) |
| 23 | Vegetation -> Water | 13,573 (2020-2025) |
| 32 | Water -> Vegetation | 24,859 (2020-2025) |
| 11 / 22 / 33 / 44 | unchanged | dominant diagonal of each matrix |

Transitions INTO Built-up (urban expansion) are the codes ending in 1: 21
(from Vegetation), 41 (from Open Land), 31 (from Water) - plus 11 (already
Built-up, unchanged). Total area that transitioned INTO Built-up: 16.50 km2
(2015-2020), 14.55 km2 (2020-2025), 26.09 km2 (2015-2025) - see
results/transition_areas.csv.
