E. SAME-YEAR VALIDATION METHODOLOGY
----------------------------------------------------------------------
  Dedupe exact duplicates BEFORE split -> stratified random PIXEL split
  80/20 (random_state=42). THIS IS NOT SPATIAL VALIDATION: neighboring
  pixels may appear in both sets (spatial autocorrelation) -> optimistic.
  Spatially independent validation was NOT implemented (no coordinates in CSVs).

F. TEMPORAL VALIDATION METHODOLOGY
----------------------------------------------------------------------
  Train on all rows of training year(s); test on whole unseen years.
  T1: 2015->2020 | T2: 2015->2025 | T3: 2015+2020->2025.
  Each model trained once per training set and reused across test years.
  Reproducibility: 6/6 experiments re-computed with exact match
  (results/final_model_results.csv vs temporal_validation_results.csv).

N. KNOWN LIMITATIONS
----------------------------------------------------------------------
  1. Label provenance could not be independently verified from the available
     project materials. Evidence consistent with derivation from the same
     imagery: RF 2015 map agreement 96.7%; 2015 CSV class mix matches label
     map exactly. Treat label-raster agreement as consistency, not accuracy.
  2. No spatially independent validation (no coordinates); random pixel
     splits are optimistic; temporal validation is the mitigation.
  3. 2025 image ~68% empty -> 2025 LULC map limited to the healthy window;
     2025 areas come from label rasters.
  4. 2020 CSV imbalance (66% Built-up vs 33.2% in map) degrades 2020 model.
  5. The cause of the substantial year-wise observation-count difference
     could not be independently verified from the available project materials.
     Empirical facts: 2015 CSV = 11.09% of map pixels with matching class
     mix; 2020/2025 = 1.77%/0.79% with class-stratified (over-sampled
     Built-up) composition.
  6. Area conversion: planar cos(lat) approximation, verified vs UTM <1%.
  7. Feature importance is not causal; indices correlate with bands.
